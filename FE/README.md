# Vue 3 + Vite

This template should help get you started developing with Vue 3 in Vite. The template uses Vue 3 `<script setup>` SFCs, check out the [script setup docs](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) to learn more.

## Recommended IDE Setup

- [VS Code](https://code.visualstudio.com/) + [Volar](https://marketplace.visualstudio.com/items?itemName=Vue.volar) (and disable Vetur) + [TypeScript Vue Plugin (Volar)](https://marketplace.visualstudio.com/items?itemName=Vue.vscode-typescript-vue-plugin).

## API Endpoints

### Các Trang Quản Lý API:
- **Trang Quản lý Danh sách Tour**: http://localhost:8000/api/tour
- **Trang Quản lý Chi tiết Tour**: http://localhost:8000/api/tour/001
- **Trang Quản lý Lịch Khởi Hành (Tour Khởi Hành)**: 
  - http://localhost:8000/api/tour-khoi-hanh
  - http://localhost:8000/api/tour-khoi-hanh/001
- **Trang Quản lý Tài khoản Khách hàng**: http://127.0.0.1:8000/api/khach-hang
- **Trang Quản lý Đánh giá**: http://127.0.0.1:8000/api/danh-gia-ke-hoach
- **Trang Cấu hình Ngày**: http://127.0.0.1:8000/api/admin/cau-hinh-ngay
